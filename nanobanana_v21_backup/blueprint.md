# 프로젝트 블루프린트

## 개요

이 프로젝트는 Svelte와 Vite를 사용하여 현재 날씨 정보를 보여주는 웹 애플리케이션입니다. OpenWeatherMap API를 통해 특정 도시의 날씨 데이터를 가져와, 미래적이고 입체적인 '나노바나나' UI로 제공하는 것을 목표로 합니다. 이 모든 아이디어와 개발 과정은 **나의 소중한 친구와 함께 만들어가는 비밀 프로젝트**입니다.

## 디자인 및 기능 (현재 버전: 나노바나나 V21.0 - 제미니 비대칭)

### 1. 전체적인 스타일
- **프로젝트 제미니 (비대칭 레이아웃)**: 화면을 비대칭적인 두 개의 패널로 분할하여 시각적 깊이와 균형을 맞춥니다. (V21.0 업데이트)
  - **왼쪽 패널 (고정폭)**: 날씨 컴포넌트를 담는 고정된 너비(32rem)를 가지며, 'AI 제네시스' 바나나 이미지를 배경으로 사용합니다.
  - **오른쪽 패널 (가변폭)**: 나머지 공간을 모두 차지하며, '우주를 유영하는 AI 바나나' 이미지를 배경으로 사용합니다.
- **AI 바나나 강림**: 강력하고 예술적인 AI 바나나 이미지를 모든 날씨 조건의 기본 배경으로 지정하여 '나노바나나'의 정체성을 완성했습니다. (V18.0 업데이트)
- **폴링 스타 텍스트**: 음식 추천 텍스트가 하늘에서 별똥별처럼 떨어지며 교체되는 수직 슬라이드 애니메이션이 적용되었습니다. (V17.1 업데이트)
- **라이트닝 스톰 효과**: 'Thunderstorm'(뇌우) 날씨일 때, 화면에 불규칙하고 강렬한 번개 섬광이 번쩍이는 극적인 시각 효과가 추가되었습니다. (V16 업데이트)
- **상세 정보 패널**: 습도(💧), 체감 온도(🌡️), 풍속(💨)을 표시합니다.
- **라이브 데이/나이트 시스템**: 시간에 따라 앱의 전체적인 모습이 동적으로 변화합니다.
- **동적 날씨 효과**: 날씨 상태에 따라 라이브 스노우, 레인, 클라우드, 썬더스톰 효과가 자동으로 나타납니다.

### 2. 기술 스택 및 구현
- **컴포넌트 기반 아키텍처**: 재사용 가능한 컴포넌트(`Snowfall.svelte`, `Thunderstorm.svelte` 등)으로 구성되어 있습니다.
- **지능형 상태 관리**: 복잡한 UI/애니메이션 상태를 제어합니다.
- **고급 애니메이션**: Svelte의 `slide` 트랜지션, `{#key}` 블록, CSS `keyframes`를 조합하여 직관적이고 몰입감 있는 사용자 경험을 제공합니다.

## 현재 변경 요청 계획

### 프로젝트 제미니: 비대칭 (완료)

1.  **비대칭 레이아웃 적용**: 왼쪽 패널은 고정폭, 오른쪽 패널은 가변폭을 갖도록 `grid-cols-[32rem_1fr]`를 사용하여 레이아웃을 수정했습니다.
2.  **시각적 균형 조정**: 날씨 정보에 집중하면서도, 광활한 우주 배경의 시각적 효과를 극대화했습니다.
